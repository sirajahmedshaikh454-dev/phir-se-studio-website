# Phir Se Studio: demo website

A multi-page demo site (plain HTML, CSS and JS) for Phir Se Studio, an upcycled patchwork home-decor business concept from Faisalabad, Pakistan.

Built with GSAP + ScrollTrigger, Lenis, Motion (Framer Motion's vanilla API) and Three.js, loaded from CDNs. No backend: the cart, wishlist and demo orders live in localStorage.

## Run it

Open `index.html` in a browser (internet needed for libraries, fonts and photos), or serve the folder:

`python -m http.server 8000`

## Notes

- Demo only: reviews, maker profiles, address, phone number and articles are made up. No order, email or payment is real.
- Photos are hotlinked from Pexels (free licence).
- `UI-SPEC.md` holds the short design contract.
